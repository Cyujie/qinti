# 青提私信

青提私信提供加密私聊、群聊和访客邀请，另设独立的采摘与签到入口。支持 Windows、macOS、Android 和 iOS 浏览器。

登录后默认进入会话列表。头像菜单的「登录后打开」可设为消息或采摘，设置随账号同步。会话按最近消息排序，已解锁会话的摘要在本机解密。会话及消息入口显示未读数，打开对应对话并在前台看到最新消息后同步已读位置。升级前的历史消息以已读作为起点。

在线地址：

https://cyujie.github.io/qinti/

## 功能

- 加密私聊与群聊、免登录邀请、文字和文件消息
- 云端会话列表、未读计数、桌面通知和按账号设置登录首页

- 根据北京时间自动判断采摘日期和类型
- 支持选择采摘日期与时间
- 支持确认采摘时间并查看预计收获串数
- 工作日、周末、工作日凌晨自动计算
- 青提收获日历和年度色块展示
- 本周、月份和年度收获统计
- 成就墙：满勤、合格、优秀、传说
- 深色和浅色主题
- 选择删除或全选删除收获记录
- JSON 导入和导出
- 手机端自适应布局

## 采摘规则

- 工作日晚间：20:30 起至 23:00 前，收获 1 串
- 周末采摘：满 3 小时收获 1 串；满 7 小时收获 2 串，最多 2 串
- 工作日凌晨：23:00–次日 07:00，基础 1 串，之后每满 30 分钟增加 1 串，最多 15 串
- 按所选北京时间自然日判断工作日或周末。23:00 起或 07:00 前为凌晨档，周末凌晨不计入青提收获

## 成就等级

- 20 串：满勤
- 40 串：合格
- 60 串：优秀
- 超过 60 串：传说

## 使用方法

1. 登录后点「采摘」。
2. 选择采摘时间，或使用当前北京时间。
3. 核对预计串数。点击“用当前时间”可以恢复自动走时。
4. 点击“立即采摘”保存本次记录。
5. 在“收获记录”页面查看日历和统计。
6. 在“收获记录”展开年度日历或累计成就。

## 数据保存说明

采摘与签到按登录账号同步到 Supabase。每个北京时间自然日最多保存一次正数采摘，0 串不占名额。签到单独保存在日历中，不增加采摘串数或次数。旧版浏览器签到可从头像菜单主动认领到当前账号。

在“采摘 → 收获记录 → 管理”导出或导入 JSON。导入先校验整份文件，再一次写入云端。同一天保留第一条正数记录，已有的日期和零串跳过。可安全重复导入。旧记录使用 30 个数量单位表示 1 串，导入保留这一格式。

## 更新网页

提交到 `main` 后，GitHub Actions 会先运行回归测试，全部通过后发布网页资源。部署完成后刷新在线地址即可看到更新。

## 在线账号与同步

网页已接入 Supabase：

- 使用邮箱和密码注册、登录、退出
- 登录后收获记录保存到在线数据库
- 同一账号可在手机、iOS 和 Windows 浏览器同步
- 每个账号只能读取和删除自己的记录

首次启用时，在 Supabase SQL Editor 中依次执行 `supabase-schema.sql` 和 `harvest-cloud.sql`。已有项目执行后者即可；若已有同一用户同日多条正数，请先核对历史记录再迁移。如果 Supabase 开启了邮箱确认，注册后需要先完成邮箱确认，再登录。

Supabase 公开客户端密钥可以放在网页中，但不要把 `service_role` 管理员密钥提交到仓库。

## 私密聊天

在「消息」中可为不同好友新建私聊、设置备注和切换会话。群名随列表同步，私聊备注会在本机解锁后显示。好友通过一次性邀请链接加入。未领取的私聊邀请在 24 小时后过期，创建者可在原会话重新生成链接。进入会话先显示最近 100 条，向上翻阅可加载更早的记录。输入框中按 Enter 发送，Shift + Enter 换行。可粘贴剪贴板中的文件，也可以点「附件」选择图片、视频或其他文件，每个最多 16 MiB。接收方点击附件即可预览支持的媒体或下载文件。

在 Windows 浏览器点「开启桌面通知」并允许通知。保留页面打开，切换标签或最小化时也能收到新消息提醒。浏览器暂停后台标签时，提醒可能延迟。

点击桌面通知会打开对应会话。该设备缺少会话密钥时会显示恢复入口。新部署依次执行 `chat-schema.sql`、`chat-attachments.sql`、`chat-groups.sql`、`chat-directory.sql` 、`chat-inbox.sql` 和 `chat-history.sql`。已有未读提醒的项目补执行 `chat-history.sql` 即可。

### 群聊

在会话列表里选择「群聊」并输入群名称。群主每点一次「邀请群成员」会生成一条独立链接，有效期 24 小时，每条可由一人领取。好友打开链接、填写昵称即可加入，并可查看群内已有消息。群聊支持加密文字与附件。群主解散群聊会一并删除消息、成员、邀请与附件。

已有私聊和附件功能的项目运行 `chat-groups.sql` 即可启用群聊。全新项目请在私聊与附件脚本之后运行群聊脚本。

### 跨设备恢复

在保存着原会话的浏览器中打开「会话列表 → 跨设备恢复 → 启用加密备份」，私下保存恢复码。会话密钥、私聊备注和原始邀请信息先在浏览器内加密，再按会话备份到账号。新设备登录同一账号后，粘贴恢复码即可解锁已备份的会话。分散在多台设备上的旧会话，需要在每台持有密钥的设备上解锁并完成一次同步。免登录访客继续使用接受邀请的浏览器。若原设备和恢复码同时丢失，无法通过云端目录解密聊天记录。

部署云端目录时，在群聊脚本之后运行 `chat-directory.sql`。

### 重命名会话

打开会话，点右上角「•••」。创建者可选「修改私聊备注」，备注加密同步到同账号持有密钥的设备；留空可恢复默认编号。群主可选「修改群名称」，保存后群内所有成员都能看到。其他设备同时编辑时，会提示重新打开确认最新名称。已有云端目录的项目重新执行最新版 `chat-directory.sql` 即可更新。
