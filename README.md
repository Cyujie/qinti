# 青提收获统计器

一个可直接在浏览器中使用的青提采摘与收获统计网页，支持 Windows、macOS、Android 和 iOS。

在线地址：

https://cyujie.github.io/qinti/

## 功能

- 根据北京时间自动判断采摘日期和类型
- 支持选择采摘日期与时间
- 支持确认采摘时间并查看预计收获串数
- 工作日、周末、工作日凌晨自动计算
- 青提收获日历和年度色块展示
- 本周、月份和年度收获统计
- 成就墙：满勤、合格、优秀、传说
- 深色和浅色主题
- 选择删除或全选删除收获记录
- JSON 导入和导出
- 手机端自适应布局

## 采摘规则

- 工作日晚间：20:30–23:00（含），收获 1 串
- 周末采摘：满 3 小时收获 1 串；满 7 小时收获 2 串，最多 2 串
- 工作日凌晨：23:00–次日 07:00，基础 1 串，之后每满 30 分钟增加 1 串，最多 15 串
- 周末凌晨：不计入青提收获

## 成就等级

- 20 串：满勤
- 40 串：合格
- 60 串：优秀
- 超过 60 串：传说

## 使用方法

1. 打开在线地址。
2. 选择采摘时间，或使用当前北京时间。
3. 点击“确认采摘时间”查看预计收获数量。
4. 点击“立即采摘”保存本次记录。
5. 在“青提收获”页面查看日历和统计。
6. 在“成就墙”页面查看累计成就。

## 数据保存说明

记录默认保存在当前浏览器的本地存储中：

- 不需要服务器即可使用。
- 不同设备和不同浏览器之间不会自动共享记录。
- 可以在“青提收获”页面导出 JSON 备份。
- 更换设备时，可使用“导入 JSON”恢复记录。

GitHub Pages 只负责发布网页文件，浏览器不能直接修改仓库中的 JSON 文件。

## 项目文件

- `index.html`：网页应用
- `note.json`：可用于导入的 JSON 数据文件
- `.github/workflows/`：GitHub Pages 自动部署配置

## 更新网页

修改 `index.html` 并提交到 `main` 分支后，GitHub Actions 会自动重新部署页面。部署完成后刷新在线地址即可看到更新。

## 在线账号与同步

网页已接入 Supabase：

- 使用邮箱和密码注册、登录、退出
- 登录后收获记录保存到在线数据库
- 同一账号可在手机、iOS 和 Windows 浏览器同步
- 每个账号只能读取和删除自己的记录

首次启用时，在 Supabase 的 SQL Editor 中执行仓库内的 `supabase-schema.sql`。如果 Supabase 开启了邮箱确认，注册后需要先完成邮箱确认，再登录。

Supabase 公开客户端密钥可以放在网页中，但不要把 `service_role` 管理员密钥提交到仓库。
